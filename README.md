# Dessert Affairs Website 
Dessert Affairs is a custom WordPress website for a dessert business, built using a modern custom-theme development workflow.

The website combines WooCommerce for e-commerce functionality with Advanced Custom Fields (ACF) for custom editable content. Timber/Twig is used for templating, while SCSS is used to organise and maintain the site's styling.

## Features
Custom WordPress Theme

The website uses a custom-built WordPress theme rather than a pre-built page builder theme.

The theme controls the overall design and presentation of the website

---

## Structure
The project separates responsibilities between WordPress, WooCommerce, ACF and the custom theme.

WooCommerce handles commerce-related data and functionality such as products, prices, cart, checkout and orders.

ACF handles custom editable website content such as hero sections, business information, catering content and other marketing sections.

Timber/Twig handles presentation and template structure.

SCSS handles the visual design and responsive styling.

This avoids duplicating functionality and keeps the website easier to maintain.
